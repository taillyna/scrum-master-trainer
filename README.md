# Scrum Master Trainer

Free Scrum Master practice questions based on the [Scrum Guide 2020](https://scrumguides.org/).

**Open the app: https://scrum-master-trainer.vercel.app/**

## Features

- 312 practice questions with explanations
- Interface and explanations in English, Deutsch, Español and Русский
- Timed mock exam: 80 questions, 60 minutes
- Review of mistakes, bookmarks, filters and progress tracking
- Works offline (installable as a PWA) and stores progress only in your browser

Static site with no build step: open `index.html`, or serve the folder with any web server (for example `npx serve`).
